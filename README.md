# AutoTech Blog — Web Application Development Final Project

## Project idea
AutoTech is a frontend blogging website for discovering famous car models, popular laptops and travel destinations.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- localStorage
- GitHub Pages

## Features
- Responsive modern frontend
- Cars category with filtering
- Laptop category with filtering
- Places/travel guides with "Things you can do"
- Search/filter-ready architecture
- Wishlist using localStorage
- Login and registration form validation
- Contact form validation
- Newsletter email validation
- Dark mode
- Responsive mobile navigation
- Detail popups
- No backend/database required

## Run in VS Code
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all project files/folders.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/root`.
6. Save and wait for GitHub Pages to publish.

## Important
This is a frontend demonstration. Login/register information and wishlist data are stored in the browser using localStorage. There is no database connection.
