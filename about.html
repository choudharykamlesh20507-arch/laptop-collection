ABOUT THE PROJECT

One blog. Three ways to explore.

AutoTech combines automotive discovery, laptop guides and destination inspiration into a single frontend experience.

OUR IDEA

Built to demonstrate strong frontend development.

This project was designed for a Web Application Development course. It demonstrates semantic HTML, responsive CSS, JavaScript DOM manipulation, filtering, search, localStorage, wishlist functionality and form validation.

There is intentionally no database. Login, registration and wishlist features are frontend demonstrations using browser storage.

Tech Stack

  • HTML5 for structure
  • CSS3 for responsive UI
  • JavaScript for interactions
  • localStorage for demo persistence
  • GitHub Pages for publishing
